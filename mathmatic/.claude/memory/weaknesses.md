재점검 대상 (해석학에서 다시 확인 예정):

- **대수 손맛 부족** — 인수분해 직진 대신 우회 (예: $(3x+1)-7$ 에 +2 끼우기). 인수분해 직진 연습 필요.
- **사전탐색 끝 `=` 슬립** — `|x-2| = ε/3` ❌ → `|x-2| < ε/3` ✓ (δ = ε/3).
- **min 모자 깜빡** — 비선형 ε-δ에서 $\delta = \epsilon/5$ 만 적고 $\min$ 빼먹기. ε 큰 영역에서 증명 붕괴.
- **단조 vs 유계 혼동** — "수렴 ⟹ 단조" 거짓 ($(-1)^n/n$ 반례). "수렴 ⟹ 유계"만 참.
- **인덱스 vs 값 혼동** — 항 번호 $n$ 과 값 $a_n$ 헷갈림. ε-N 가정은 항 번호 ($n \ge k$) 를 통제.
- **strict 부호 추적** — 사슬에 `<` 한 줄이라도 끼면 전체 `<`.

**교정된 오개념:**
- "수렴수열은 단조증가/감소" → 거짓. 진동 수렴 가능, 유계만 보장.
- "함수극한의 δ는 정의역 오차" → "오차"보다 "이웃 반경"이 정확.
