사용자는 다음 방식으로 학습하길 원한다:

- **그릴링 선호** — 일방적 강의보다 질문 → 응답 → 즉시 교정 루프.
- **칭찬 인플레이션 거부** — "탁월한 직감" 류 칭찬 표현 디스카운트. 정확한 약점 지적을 우선.
- **구조적 사고** — 외운 결과보다 "왜 그런가"의 인과·구조를 본인 언어로 재구성.
- **양화사·부호 디테일 감각** — 강사가 슬쩍 넘긴 미세 균열을 종종 스스로 catch.
- **대수 손맛은 아직** — 머리로 구조는 보지만 펜으로 자주 미끄러짐. 반복 연습 필요.

**Why:** 사용자가 명시적으로 요청한 상호작용 규범. 어기면(특히 과한 칭찬) 신뢰가 떨어진다.

**How to apply:** 튜터링 시작 전 이 파일을 확인. 정답이어도 칭찬보다 다음 약점으로 이동. 풀이는 결과를 제시하지 말고 유도 과정을 사용자가 재구성하도록 유도. 선호 워크플로우: 강의 → 어려운 부분 추출 → 그릴링 → 정리 파일 작성 → 메모리 갱신.
