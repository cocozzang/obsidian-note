새 정리를 만날 때 어떤 도구가 적용 가능한지 빠르게 스캔하기 위한 누적 목록.

| 도구 | 첫 등장 | 용도 |
| --- | --- | --- |
| 양화사 순서 의식 | 2026-05-30 | 정의의 의미 해석 |
| `k(ε)`, `δ(ε)` 종속성 | 2026-05-30 | 응답 변수가 자유변수에 오염되지 않도록 |
| 삼각부등식 상한 | 2026-05-30 | 분자 진동 처리 |
| 이중 제약 + `min` | 2026-05-30 | 비선형 ε-δ의 변수 인자 통제 |
| 분자 상한 vs 분모 하한 | 2026-05-30 | 분수 함수 ε-δ |
| 역수 부등호 뒤집기 | 2026-05-30 | 분모 변수 케이스 핵심 변환 (양수일 때만) |
| `+1` padding | 2026-05-30 | 0으로 나누기 회피 (분모 strict 양수화) |
| 가감 트릭 (add-subtract) | 2026-05-30 | 직접 안 보이는 무기 등장시키기 |
| ε/2 (ε/N) 분배 | 2026-05-30 | 합 형태 부등식의 조각별 통제 |
| `max(N₁, N₂)` | 2026-05-30 | 다중 ε-N 가정 동시 발동 |
| 수렴 ⟹ 유계 | 2026-05-30 | 머리(유한) max + 꼬리(무한) ε-N 가둠 |
| Strict 부호 전염 | 2026-05-30 | 사슬 한 줄이라도 `<` 면 전체 `<` |
| 귀류법 + ε/2 분리 | 2026-06-03 | 유일성·부등식보존: $d=\|L_1-L_2\|$, $\epsilon=\frac d2$, 삼각부등식으로 $d<d$ 모순 |
| `min(δ₁, δ₂)` | 2026-06-03 | 다중 ε-δ 가정 동시 발동 (max(N₁,N₂)의 함수극한판) |
| 분자형 판정식 (상한)·(ε계수)≤1 | 2026-06-03 | "성립하는 δ" 판정. ε이 약분돼 ε-무관 상수조건만 남음 |
| 결론 제곱해 δ 역산 | 2026-06-03 | $\sqrt{}$·거듭제곱 극한: $\sqrt x<\epsilon\iff x<\epsilon^2$ → $\delta=\epsilon^2$ |
| 좌우극한 절댓값 벗기기 | 2026-06-03 | $x<a$ 면 $\|x-a\|=a-x$ (부호 뒤집기), $x>a$ 면 그대로. $A<B<0\Rightarrow\|A\|>\|B\|$ |
| 분모 하한 $\|g\|>\frac{\|M\|}{2}$ | 2026-06-03 | 몫의 극한 $\lim\frac1g=\frac1M$. 분수형 ε-δ(\|x\|>2 등)의 추상 일반화 |
| 극한법칙 증명의 δ는 받아오는 것 | 2026-06-03 | f,g 임의라 δ 직접계산 불가. 하위극한에서 δ₁,δ₂ 받아 min (정밀도 ε/2 ≠ 울타리 δ) |
| 양화사 4종 (ε-δ/ε-M/M-δ) | 2026-06-03 | x→∞면 가정변형(δ→M문턱), f→∞면 결론변형(ε→M목표) |
