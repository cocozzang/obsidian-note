# 2026-06-03 — 좌우극한 / 극한 유일성 / 극한 기본정리

**출처:** 큐스터디 권태원 대학미적분학1 5강(함수의 극한2: 좌극한·우극한), 6강(함수의 극한3: 극한 기본정리)

> 직전 4강 보강(분수형·분자형 ε-δ 드릴)도 같은 흐름에서 진행. 엡실론 논법 단원(1~6강) 전체 마감.

## 다룬 범위

**4강 보강 (ε-δ 실행 드릴)**
- 분수형 ε-δ: $\lim_{x\to-1}\frac{x}{2x+1}=1$ — 국소화반경 $d<\frac12$ (목표점→특이점 거리), $\delta=\min(d,(1-2d)\epsilon)$
- 분자형 판정 (보충ex): $\lim_{x\to2}x^2=4$ 의 "성립 안 하는 δ" 고르기 — **판정식 (상한)·(ε계수) ≤ 1**
- 분수형 양쪽특이점 드릴: $\lim_{x\to1}\frac{1}{x^2}=1$ — 분자 위·분모 아래 동시 묶기, $\delta=\min(\frac12,\frac{\epsilon}{10})$
- 제곱근: $\lim_{x\to0^+}\sqrt x=0$ — 결론 제곱해 δ 역산, $\delta=\epsilon^2$

**5강 (좌극한·우극한)**
- Def(2): 우극한 $0<x-a<\delta$ / 좌극한 $-\delta<x-a<0$. "0<"가 방향+($x\ne a$) 동시 담당
- 부등식을 "벽" 비유로: δ는 바깥벽(반경)만, 안쪽벽(방향·중심)은 부등호 형태가 결정
- 예제7 조각함수 좌우극한 (좌3 우1 → 양쪽극한 부존재)
- 예제9 $x-[x]$ 톱니: 정수점 좌우극한 다름
- **Thm(1)**: 양쪽극한 $\iff$ 좌·우극한 같음. (⟹)(⟸) 양방향 직접 증명

**6강 (극한 기본정리)**
- **극한 유일성** (귀류법+ε/2): $d=|L_1-L_2|>0$, $\epsilon=\frac d2$, 삼각부등식으로 $d<d$ 모순. 자력 완주
- **합의 극한** $\lim(f+g)=L+M$: ε/2 두 조각, $\delta=\min(\delta_1,\delta_2)$
- **곱의 극한**: ε-N 버전과 동형. 자료는 유계화를 $\min(1,\frac{\epsilon}{2|M|})$에 압축 + $|L|+1$ 패딩
- **몫의 극한** $\lim\frac1g=\frac1M$: 분모 하한 $|g|>\frac{|M|}{2}\Rightarrow\frac1{|g|}<\frac2{|M|}$. 분수형 ε-δ의 일반화
- 예제12 부등식 보존 (f≥g ⟹ lim f≥lim g): 유일성과 같은 귀류법 골격
- Def(3) ε-M (x→∞): δ-반경 → M-문턱 (가정 쪽 변형)
- Def(4) M-δ (f→∞): ε-목표 → M-목표, 결론 $f(x)>M$ (결론 쪽 변형)

## 자력 통찰 / 잘한 것

- **유일성 귀류법 자력 완주** — 귀류법 부정, ε=d/2 선택, 가감트릭+삼각부등식, $d<d$ 모순까지 스스로
- **"성립 안 하는 δ" 판정**을 본인 방식(사슬 끝까지 곱해 계수≤1 확인)으로 재구성
- **분수형 양쪽특이점**에서 분모 방향 뒤집힘(처음 $x^2$ 위로 묶음)을 자가 교정
- **⟹/⟸ 구조** 처음엔 "모르겠다"였으나, 가정·목표가 두 방향에서 맞바뀐다는 것 + 정보 강약 비대칭(⟹ 하나로 쪼갬 / ⟸ min 합성)까지 도달
- **양화사 4종 지도**(ε-δ / ε-M / M-δ) 본인 언어로 "안 vs 바깥", "오차↓ vs 높이↑" 대비
