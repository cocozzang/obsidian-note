# 2026-05-30 — ε-N / ε-δ 논법

**출처:** 큐스터디 권태원 대학미적분학1

**다룬 범위**
- 수열 극한 ε-N 논법 (정의, 양화사 순서, 예제, 곱의 극한 정리)
- 함수 극한 ε-δ 논법 (정의, 선형/비선형 분자/비선형 분모 케이스)

**졸업한 기술**
- ε-N 양화사 순서 (`∀ε, ∃k` vs `∃k, ∀ε`) — 뒤집힌 명제는 종국적 상수수열만 잡음
- $k = k(\epsilon)$, $\delta = \delta(\epsilon)$ 종속성 원칙
- 선형 ε-δ — 사전탐색부터 자력 도출
- 비선형 ε-δ 이중 제약 + `min` — 분자 변수 ($x^2$) 와 분모 변수 ($1/x$) 모두
- 곱의 극한 — 가감 트릭, 삼각부등식, 수렴⟹유계, ε/2 분배, $\max(N_1, N_2)$

**자력 통찰 3종** (그릴링 중 스스로 catch)
1. `|β|+1` padding — 분모 0 회피
2. `M+1` padding — 상수수열 $a_n = 0$ 케이스에서 유계상수 M=0 가능성
3. Strict 부등호 전염 — 사슬에 `<` 한 줄이라도 끼면 전체 `<`

→ 통합 원리: **"분모에 들어갈 양은 +1 padding으로 strict 양수화. 사슬 끝은 `≤ ε`으로 닫힘. 0 케이스 자동 흡수."**
